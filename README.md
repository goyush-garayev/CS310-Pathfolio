# PathFolio: Travel Planner

A Flutter mobile app that turns a traveler's destination, dates, interests, pace and budget into a personalized day-by-day travel plan.

# Description
PathFolio generates an itinerary with time slots, short descriptions and estimated costs. Users can remove or reorder activities, regenerate a single day, add custom activities and save plans on the device. No account is needed.
